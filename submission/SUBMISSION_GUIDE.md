# Submission Guide

## 1. Create the repository under Mettelo

Create:

```text
MTL-XF-011-<team-name>
```

under the **Mettelo GitHub organisation**.

## 2. Add the project team

Add every team member to the repository with their own GitHub account.

## 3. Establish the repository structure

Follow `TEAM_REPOSITORY_STANDARD.md`.

## 4. Deliver through GitHub

Use issues, branches, commits, pull requests, reviews and documentation throughout the engagement rather than uploading everything at the end.

## 5. Complete all D1–D12 deliverables

Link every deliverable from the final submission file.

## 6. Complete final QA

Confirm:

- [ ] repository is under the Mettelo organisation;
- [ ] all team members have been added individually;
- [ ] contribution history is visible;
- [ ] frozen data/source instructions are reproducible;
- [ ] requirements and governance artefacts are present;
- [ ] D1–D12 are complete;
- [ ] dashboard/product is accessible;
- [ ] UAT/assurance evidence is present;
- [ ] no secrets are committed;
- [ ] limitations are explicit;
- [ ] `CONTRIBUTIONS.md` is complete.

## 7. Freeze submission

Create tag/release:

```text
v1.0-mettelo-submission
```

Submit the repository URL to Mettelo.
