# Mandatory Team Repository Standard

## Repository Location

Create the team delivery repository **under the Mettelo GitHub organisation**.

Recommended name:

```text
MTL-XF-011-<team-name>
```

The Team Lead should then add every team member to that repository using each member's individual GitHub account.

## Required Structure

├── README.md
├── CONTRIBUTIONS.md
├── requirements.txt
├── .gitignore
├── data/

## Collaboration Evidence

Expected evidence includes issues, meaningful commits, branches, PRs, reviews where practical, tests/QA and contribution from multiple members.

One final bulk upload by one person is not appropriate evidence of collaborative delivery.

## Contribution Evidence

`CONTRIBUTIONS.md` records actual contribution. Commit count alone is not proof of capability.
