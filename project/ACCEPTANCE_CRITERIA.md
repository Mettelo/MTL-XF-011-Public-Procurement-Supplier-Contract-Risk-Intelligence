# Agreed Acceptance Criteria

These criteria define the minimum standard for Mettelo sign-off.

1. **AC1:** All June 2026 source files used are listed with filename, source URL, acquisition date and record count.
2. **AC2:** A documented rule prevents duplicate/amended notices from being double counted in core metrics.
3. **AC3:** At least 95% of records entering the curated award/notices table reconcile to an explicit included/excluded/error category.
4. **AC4:** Supplier concentration metrics can be reproduced from code and trace back to source fields.
5. **AC5:** Every executive KPI has definition, grain, owner, calculation, exclusions and limitation in the KPI catalogue.
6. **AC6:** The prioritisation framework uses documented factors and does not label suppliers as financially or operationally risky without evidence.
7. **AC7:** Dashboard totals reconcile to the curated analytical table for at least five agreed headline measures.
8. **AC8:** A reviewer can clone the team repo, obtain the documented source files, run the pipeline and regenerate the curated tables and validation output without undocumented manual edits.

## Sign-off Rule

The project is not complete because all files exist. The review panel must be able to verify the business, data, analytical, product and reproducibility criteria above from repository evidence.

## Evidence Mapping

The team should maintain a simple table mapping each acceptance criterion to:
- requirement(s);
- artefact(s);
- test/reconciliation evidence;
- owner;
- status.
